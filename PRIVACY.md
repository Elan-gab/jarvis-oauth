# Política de Privacidade — Jarvis

**Data de vigência:** 2026-09-11

## Controlador / operador

Este projeto é operado por **Elan-gab** (projeto Jarvis). Para contato, utilize as **Issues** deste repositório: https://github.com/Elan-gab/jarvis-oauth/issues

## Dados do Google obtidos

Com a autorização do usuário, o Jarvis acessa **eventos e metadados do Google Calendar** conforme os escopos OAuth autorizados (por exemplo: criar, listar e atualizar eventos).

**Não** solicitamos acesso a Gmail, Google Drive ou outros serviços Google neste fluxo.

## Finalidade do uso

Os dados do Calendar são usados **exclusivamente** para executar pedidos do usuário no WhatsApp — por exemplo, criar um evento ou tarefa na Agenda, consultar compromissos ou configurar lembretes conforme solicitado.

## Armazenamento

Tokens OAuth e demais dados necessários ao funcionamento do bot ficam no **ambiente privado do operador**.

- Não vendemos dados.
- Não usamos dados do Calendar para publicidade.
- Não treinamos modelos de terceiros com dados do Calendar do usuário.

## Compartilhamento

Não compartilhamos dados do Calendar com terceiros, exceto:

- **Google** — via APIs oficiais do Google Calendar, conforme autorizado pelo usuário.
- **O próprio usuário** — respostas e confirmações enviadas via WhatsApp.

## Retenção

Os dados são mantidos **enquanto a autorização OAuth estiver ativa** e forem necessários ao funcionamento do bot. O usuário pode revogar o acesso a qualquer momento e solicitar exclusão de dados relacionados abrindo uma Issue neste repositório.

## Revogação de acesso

Revogue a autorização em: https://myaccount.google.com/permissions

Também em: **Conta Google → Segurança → Conexões com apps de terceiros**.

## Limited Use (Google API Services User Data Policy)

O uso dos dados obtidos via APIs Google está **limitado** aos propósitos divulgados nesta política e na tela de consentimento OAuth, em conformidade com a [Google API Services User Data Policy](https://developers.google.com/terms/api-services-user-data-policy), incluindo os requisitos de **Limited Use**.

## Alterações

Esta política pode ser atualizada. A data de vigência no topo indica a versão em force. Alterações relevantes serão refletidas neste arquivo no repositório.
