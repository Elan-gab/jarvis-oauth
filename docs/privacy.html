Política de Privacidade — Jarvis

Vigência: 2026-09-11

Controlador

Operado por Elan-gab. Contato: GitHub Issues.

Dados Google

Com autorização OAuth, acessamos eventos do Google Calendar (criar, listar, atualizar). Não solicitamos Gmail, Drive ou outros serviços.

Finalidade

Executar pedidos do usuário no WhatsApp (eventos, consultas, lembretes na Agenda).

Armazenamento

Tokens e dados ficam no ambiente privado do operador. Sem venda de dados, sem ads, sem treinar modelos de terceiros com dados do Calendar.

Compartilhamento

Apenas Google (APIs oficiais) e o próprio usuário (respostas no WhatsApp).

Retenção e revogação

Dados mantidos enquanto a autorização OAuth estiver ativa. Revogue em myaccount.google.com/permissions.

Limited Use

Conforme Google API Services User Data Policy (Limited Use).
